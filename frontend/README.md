This is the Book It All website and installable web app. Android and iOS are in the `mobile/` Flutter app.

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Location setup

The vendor location picker uses server-side Google reverse geocoding to resolve house numbers and building names. Add `GOOGLE_MAPS_API_KEY` to the frontend deployment environment (Vercel: Project Settings -> Environment Variables) and redeploy. Enable Geocoding API and Places API for that key, and configure restrictions suitable for server-side requests.

The key must be configured in the frontend deployment, not only in the backend environment, because `/api/location/reverse` and `/api/location/search` are Next.js route handlers.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
